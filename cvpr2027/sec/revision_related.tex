\section{Related Work}
\label{sec:related}

\paragraph{Reducing codec complexity.}
Shallow synthesis trades decoder work for stronger analysis or iterative
encoding~\cite{yang2023shallow}. DCVC-RT attacks memory traffic and
function-call overhead~\cite{jia2025dcvcrt}; DCVC-UF streamlines
entropy interaction~\cite{li2026dcvcuf}. Our intra extension instead
asks which regions merit additional synthesis. Modelled MACs and
complete execution time are reported separately.

\paragraph{Spatial network selection and early exit.}
ClassSR assigns restoration patches to networks of different
capacity~\cite{kong2021classsr}; APE predicts the incremental value of
later layers in a shared multi-exit network~\cite{wang2022ape}.
AdaRevD routes deblurring patches~\cite{mao2024adarevd}, and RBQE
terminates enhancement early~\cite{xing2020rbqe}. Swift provides
compute-dependent exits in layered video decoding, at different output
resolutions~\cite{dasari2022swift}. RegLIC's evaluated path retains one
entropy-decoded latent and a fixed output resolution while processing
only surviving tiles through later blocks.

\paragraph{Adaptive learned compression.}
Slimmable autoencoders optimise multiple widths~\cite{yang2021slimcae};
ELFIC selects per-instance decode complexity~\cite{zhang2023elfic};
ABC adapts structure to content and budget~\cite{zhang2025abc}.
AdaNIC routes spatial transform capacity~\cite{tao2023adanic}, and
cgSlimDecoder allocates video-decoder channels~\cite{hu2023cgslim}.
MixCompress selects depth experts using rate embeddings rather than
image content~\cite{ta2026mixcompress}. RegLIC uses constant-width
synthesis depth and compares learned placement against blind mixtures
with the same available depths.

\paragraph{Independent codecs and region boundaries.}
Blard et al. select among content-specialised complete codecs and
jointly process connected same-mode regions~\cite{blard2026spatial}.
Our prospective bank instead varies synthesis depth and chooses a
codec before encoding; shared exit holds the representation fixed.
Boundary context matters in either case. Kim et al. preserve full-image
CNN reconstruction using overlap rules~\cite{kim2026blockwise};
our zero-halo conditional suffix accepts context loss and learns
full-frame repair, so tiled and full-frame controls remain distinct.
