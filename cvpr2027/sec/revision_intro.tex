\section{Introduction}
\label{sec:intro}

A reconstructed image contains regions with different demands on a decoder.
A smooth background and a textured object pass through the same sequence of
synthesis blocks, even when the additional depth has different value in the
two regions. Modern learned codecs have made this sequence increasingly
fast. Their next efficiency opportunity is therefore not only to execute
each block faster, but to decide which regions need to execute it at all.

We study this opportunity in the intra model supplied with
DCVC-UF~\cite{li2026dcvcuf}. Its synthesis transform offers a natural place
to vary computation: a stack of twelve constant-width blocks between an
upsampling stage and a reconstruction head. Removing later blocks reduces
synthesis work without requiring a different coded latent. Yet simply
truncating the stack is insufficient. Intermediate features were not trained
to be final reconstructions; independent tile execution changes boundary
context; and deciding where to stop can consume some of the work it saves.
A useful early-exit codec must address these three issues together.

FLEX-UF turns the synthesis stack into a nested spatial decoder
(\cref{fig:system}). An initial full-frame stem preserves common context.
Thereafter, each tile continues only as far as its assigned depth.
Exit-specific pointwise adapters make intermediate features suitable for a
common output space. A lightweight repair on the stitched feature canvas and
a shared reconstruction head restore cross-tile communication near the
output. This arrangement concentrates adaptive execution in the expensive
trunk, while retaining a single analysis transform and entropy model.

The stopping rule is deliberately separated from the execution mechanism.
At the encoder, the source image can supervise a search over reconstruction
error. At the decoder, a compact router can use already recovered features.
The former provides a useful decision reference but requires trial
reconstructions; the latter can avoid that acquisition cost only when its
control is calibrated without the test source. We evaluate the current
source-calibrated policy family and make the remaining deployment experiment
explicit. This distinction lets the architecture be assessed without
confusing an inexpensive score prediction with an inexpensive complete
encoding procedure.

Our experiments ask how much of the saving comes from early exit, and how
much specifically comes from selecting its spatial locations. Uniform depth
measures the first effect. Ordered dithering adds finer average costs
without predicting which region benefits from deeper synthesis. Learned
routing contributes a further \MainPremium\ percentage points at the
0.1\,dB target, on top of a \MainDitherSaving\% blind-mixture saving.
That contribution decreases near the ladder's arithmetic ceiling. The
result is a useful design principle: content adaptation matters most where
several depths remain competitive, rather than where nearly all tiles can
already take the cheapest exit.

This paper makes three contributions. First, it develops a DCVC-UF spatial
early-exit path with shared-prefix execution, pointwise exit adaptation and
full-frame boundary repair. Second, it evaluates the quality--arithmetic
frontier using common reconstructions, strong spatially blind controls and
paired uncertainty estimates. Third, it characterises where spatial
adaptation adds value: the learned margin contracts as the shallowest exit
saturates, while obtaining the stopping decision has its own encoder cost.
The completed evidence is confined to DCVC-UF intra decoding. A controlled
six-depth study is specified to separate shared-exit adaptation from
independent capacity; its ongoing trainings and analytical scenarios are
kept separate from measured reconstruction results.
