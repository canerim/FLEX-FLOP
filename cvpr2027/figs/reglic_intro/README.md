# Introduction evidence figure

`intro_evidence.pdf` is the figure used by `main.tex`. It is generated by
`make_intro_evidence.py` from `data/gallery20260928/gallery.json` and its
SHA256-checked `source_luma.npz` archive. The two examples are fixed gallery
indices 0 and 7 (the first and last entries of the predeclared gallery),
not a search for favourable routing outcomes. Both use the archived QP32,
nominal 0.1 dB, source-calibrated shared-exit map. Map indices 2/3/4/5
correspond to 6/8/10/12 executed synthesis blocks. The source panel shows
input luma, not the reconstruction. The map is an allocation visualisation,
not evidence of perceptual quality or a source-independent routing gain.

The PDF contains raster source pixels and vector annotation/grid elements;
SVG and PNG are provided for inspection. Reproduce with:

```sh
python3 figs/reglic_intro/make_intro_evidence.py
```

The prior synthetic concept image was removed from the active paper.
