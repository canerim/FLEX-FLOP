# RegLIC introduction figure

Run `python3 make_intro.py` from this directory or `python3
figs/reglic_intro/make_intro.py` from the paper root. The bottom panel
reads the source-calibrated QP sweep values from
`data/refresh20260927/macros.tex`: router 27.97% and ordered dithering
25.43% modelled synthesis-MAC saving at nominal 0.1 dB. The spatial
field above is deliberately schematic; it is not a learned route map
or a measured local-gain image. The figure does not imply codec
latency savings or results for the independently trained depth bank.
