# RegLIC introduction illustration

`reglic_concept_20261002.png` is an AI-generated conceptual illustration.
It depicts one scene above a continuous shared substrate, with different
amounts of synthesis below three regions. The source image is synthetic;
the layer counts and region boundaries are not measured outputs or exact
DCVC-UF tensors. It is deliberately free of text, charts and performance
values. The generated source is retained under Codex's generated-images
archive; the project copy is the asset compiled by `main.tex`.
