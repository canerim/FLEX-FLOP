# paper_figures

Hand-drawn-diagram material, generated by `scripts/make_patch_assets.py`.

Source: `Bosphorus_1920x1080_120fps_420_8bit_YUV.yuv`, frame 0, padded from 1920x1080 to 2048x1280 so the 256 px lattice divides it exactly — which is what the decoder does before it tiles anything.

| file | what |
|---|---|
| `frame_full.png` | the padded frame, no marks |
| `frame_grid.png` | the same, with the 5x8 tile lattice |
| `frame_grid_marked.png` | the same, with the three example tiles outlined |
| `patch_1_hillside.png` | tile at row 0, col 1 |
| `patch_2_boat.png` | tile at row 2, col 3 |
| `patch_3_water.png` | tile at row 3, col 6 |

Colours are converted from the decoder's YCbCr 4:4:4 with `src.utils.transforms.ycbcr2rgb`; displaying those tensors directly renders the picture pink.
