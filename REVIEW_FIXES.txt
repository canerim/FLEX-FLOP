[x] 01. The "bitstream unchanged" claim contradicts the headline number.
        The contribution says deployable against existing bitstreams and then
        quotes 29.9-15.6%, which is configuration A, and A transmits an exit map
        of about 89 bits per frame. Table 5 is A. The conclusion repeats "no
        change to the coded payload" for the same numbers.
        FIX: define two operating modes explicitly and use the names everywhere.
        signalled FLEX-UF  = coded latent unchanged, plus ~X bits/frame of
                             routing metadata
        bitstream-identical FLEX-UF = decoder-side router, byte-identical file
        If the headline stays A, the abstract must say "no change to the coded
        latent, only ~X bits per frame of routing metadata". If we want the
        "existing byte-identical bitstreams" headline, then B or the bit rule
        becomes the headline.
        Files: main.tex, build_pdf.py, abstract, contributions, conclusion,
        Table 5 caption, related-work table.

[x] 02. Freeze the cost accounting on ONE canonical definition.
        Three different architectural ceilings are in circulation for the same
        quantity: 41.91%, 39.1%, 38.33%. The supplement says 38.33% is the one
        that agrees with the hook-measured cost, and that the hook audit moves
        the headline from 29.9 to 29.13 and 15.6 to 15.16. Main Table 16 still
        prints 41.9 while the text under it argues from 39.1.
        FIX: choose the authoritative MAC definition, then regenerate every
        table, figure and abstract number from one script. No new experiment.

[x] 03. Recompute BD-Rate 0.88% on the pinned checkpoint.
        The supplement states that no integrated figure in this work is on the
        pinned checkpoint. The file the 0.88% comes from does not even record
        its checkpoint and predates the corrected cost model. This is one of the
        two most important numbers in the abstract.
        FIX: regenerate BD-Rate once, on the final checkpoint, with the final
        evaluation convention and the final bitrate accounting. Evaluation only.

[x] 04. Say how beta is chosen at deployment time in configuration B.
        The paper correctly says the decoder cannot compute D(t,k), then says
        beta is bisected against the budget exactly as lambda is. A real decoder
        cannot know whether it hit 0.1 dB without the source. As written this
        reads as test-time oracle leakage.
        FIX: state the calibration protocol in the main paper. Choose beta on a
        held-out calibration set, per (quality index, budget), and evaluate on
        the test set with that fixed beta. Say whether the table is global,
        per-rate or per-frame. Evaluation only, small, high value.

[x] 05. "Parameter-free router" is not defensible as written.
        The complete rule fits (alpha, c, phi) by least squares with
        leave-one-sequence-out calibration, and the supplement lists six offline
        calibration constants per rate. Zero LEARNED parameters, not zero
        parameters.
        FIX: rename throughout to something honest and equally strong:
        "training-free calibrated bit rule", "zero-learned-parameter router", or
        "scalar-calibrated rule". The contribution survives the rename.

[x] 06. Narrow the word "oracle".
        Configuration C beats A at the same distortion with half a map, and the
        paper explains why: A is optimal only within the single-multiplier
        Lagrangian family. Calling A "the oracle" without qualification misleads.
        FIX: "Lagrangian oracle" or "single-multiplier oracle" everywhere, and
        reserve "global constrained optimum" for the exact Pareto point.

[x] 07. The hybrid endpoint consistency check is failing. Resolve it.
        check_paper is 84/85 and the open failure is "hybrid: rho=1 reproduces
        A", while the main text makes the strong claim that it does. This is an
        internal correctness condition, not a limitation.
        FIX: either repair the code path or delete the claim. DECISIONS 91.

[x] 08. The deblocking-filter narrative contradicts itself.
        The section is titled "A learned deblocking filter, and why we reject
        it", yet the shipped configuration still pays for it: Table 6 blames it
        for the deepest exit costing more than the release, and the supplement's
        cost model carries r = 0.0095 for a full-frame filter.
        FIX: either remove it from the shipped configuration and regenerate the
        costs, or retitle and rewrite the verdict, for instance "why it is not
        sufficient".

        "rate-ranked (free)" invites the reader to think they are one algorithm.

[x] 23. Promote the free baseline beating the trained head to a main result.
        It wins at 5 of 5 rates at 0.1 dB despite worse oracle agreement.
        FIX: state the insight crisply. Classification accuracy over exit labels
        is a poor router objective; regret and ranking are what matter. This
        lifts the paper from an early-exit trick to a general point about
        adaptive inference.

[x] 24. Note the additivity assumption in the main Method.

        FIX: one sentence before the theory, pointing at the check.

The workflow that closed them wrote its edits into paper/main.tex and
scripts/build_pdf.py. Those two files were then restored from an earlier commit,
because the same workflow had also cut the paper to eight pages and the limit had
moved to sixteen. The restore took the wording fixes with it. The ticks did not
survive an audit of the built PDF: the deblocking section still says "why we
reject it", there is no evaluation-protocol box, "not converged" is still bare,
"any spatially adaptive decoder" is still there, a router per operating point is
still proposed, and the bit rule is still absent from the first two pages.

Item 28 is the exception and stays ticked: the supplement trimming lives in
scripts/supp/ and was not touched by the restore.

The lesson is the one this project keeps relearning: a tick is a claim, and a
claim needs evidence in the artefact, not in the process that was supposed to
produce it.
