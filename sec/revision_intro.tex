\section{Introduction}
\label{sec:intro}

An image does not demand the same reconstruction effort everywhere.
Additional synthesis layers may recover detail in one region while changing
another very little. Yet a conventional learned codec commits both regions
to the same network depth. Faster operators reduce the price of this uniform
computation; spatial adaptation asks a complementary question: \emph{where
is the next unit of computation worth spending?}

We investigate this question in the intra model supplied with
DCVC-UF~\cite{li2026dcvcuf}. Its synthesis transform contains twelve
constant-width blocks between upsampling and reconstruction, providing a
concrete axis along which to vary capacity. Our aim is to turn that fixed
stack into an image-dependent allocation of work. The relevant signal is
not visual complexity alone. A textured patch need not benefit most from
the next block pair at every bitrate; allocation should reflect the
reconstruction benefit of additional computation under the chosen quality
constraint.

There are two natural ways to make this decision
(\cref{fig:overview}). \emph{Across models}, a selector assigns each patch
to a codec of suitable capacity, following the patch-to-network principle
of ClassSR~\cite{kong2021classsr}. \emph{Within a model}, a stopping rule
lets different patches leave a shared synthesis stack at different depths,
related to adaptive patch exiting~\cite{wang2022ape}. Both approaches make
computation spatially variable, but they make different commitments.
Independent codecs can specialise their representations; nested exits reuse
one representation and the computation already performed. FLEX-UF takes
shared early exit as its first implemented and evaluated mechanism, and
uses a controlled independent-depth study to investigate this trade-off.

Inside a codec, early exit requires more than attaching intermediate
outputs. Features at different depths must support a common reconstruction;
conditional tiles lose some spatial context; and choosing an exit can itself
require expensive candidate decoding. FLEX-UF addresses execution with a
full-frame stem, a shrinking batch of active tiles, pointwise exit adapters,
and a shared repair and reconstruction head. Only surviving tiles traverse
the next block pair. The frozen analysis and entropy path supplies one
common latent, so synthesis effort can vary without independently encoding
every candidate depth.

We then separate the value of \emph{cheaper depth} from the value of
\emph{content-dependent placement}. Uniform depth tests global truncation.
Ordered dithering permits mixtures of depths without predicting where
extra synthesis is useful. Learned routing improves on this stronger
control by \MainPremium\ percentage points of synthesis MAC saving at a
nominal 0.1\,dB target, above dithering's \MainDitherSaving\% reduction.
That increment shrinks near the shallowest-exit ceiling. This pattern
locates the useful regime for adaptation: there must be both remaining
compute to remove and meaningful differences in where deeper processing
helps. A common delivered-loss analysis retains the same qualitative result.

We contribute a spatially conditional DCVC-UF synthesis path with reusable
prefixes, aligned exits and full-frame boundary repair, and a controlled
evaluation that separates cheaper depth from useful spatial placement.
Blind mixtures, paired uncertainty estimates and a common measured-loss
cap expose when learned allocation adds value and when its margin contracts.
The six-depth independent-codec study then tests the complementary cost of
specialisation; its ongoing training is not counted as a completed routing
result. The present stopping controls use source calibration. Autonomous
selection and complete codec speedups require the next experimental stage.
