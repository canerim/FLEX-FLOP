# Fixed-map region coalescing control

Declared2026-09-27T18:57UTC, before inspecting completed patch or native-padding quality results. No adaptive router is fitted. All16 predeclared DIV2K crops and QPs0/16/32/48/63 are retained. Checkpoints are the frozen epoch20 D2 and D6; no released-versus-interim confound occurs within this control.

For each image, use both phases of each fixed50/50 depth assignment: checkerboard, vertical halves and horizontal halves. Four256-square cores define the unmerged grids. The vertical/horizontal maps also have a coalesced implementation with two512×256 or256×512 regions. Each implementation retains the identical depth for every source pixel. Context halo32 is clipped to the512 crop. FUFREF2's image16/latent4 padding geometry is used. Checkerboards have no equal-depth neighbours and therefore remain four independent regions.

Ten fixed profiles per image/QP: two checkerboard; two unmerged and two merged vertical; two unmerged and two merged horizontal. Unmerged component streams are reused, hash-checked and independently decoded from the completed native-padding control. Merged component streams are newly encoded and independently decoded. A small, versioned research container stores the fixed profile index and component lengths; profile geometry is part of the decoder protocol. Each embedded FUFREF2 stream includes its own model/shape/QP/integrity fields. Decoder receives only the container and resident D2/D6 models. Report summed entropy payload, embedded-stream bytes and complete container bytes separately. This framing is not a minimum production format or the native CUDA format.

Primary contrasts compare merged versus unmerged versions of the *same* fixed map. Both complementary phases are retained and averaged within image before image bootstrap, avoiding phase pseudoreplication. Report all five native QPs, same-QP byte differences, and per-image matched actual payload/container rate differences on common measured support at0.1/0.2/0.4bpp. No extrapolation or favourable-image selection. Seam and internal-boundary errors are diagnostics, not independent samples.

The study is an engineering ablation of connected-region execution, not a novelty claim: Spatial Competition already processes same-mode connected regions continuously (arXiv2605.13243v1§2.2). It is not learned content adaptation, final-model quality, a shared-exit comparison or native runtime. A new source-disjoint test set and measured routing/grouping costs remain required for the future bank.
