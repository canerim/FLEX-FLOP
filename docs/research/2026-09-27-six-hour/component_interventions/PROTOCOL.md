# Frozen-component intervention

Declared 28 September 2026 before intervention outcomes. All 53 CTC first frames, QP32, the archived Q90 router map at nominal 0.1 dB from the complete cross-fit replay. Four states: trained components, repair replaced by identity, adapters replaced by identity, both replaced by identity. Same checkpoint, latent, map, full-frame head and valid support throughout. No map reselection or weight updates. Explicit RGB conversion/clipping; global, boundary and interior MSE. Boundary is the union of 8-pixel-wide bands centred on internal 256-pixel tile boundaries. All sequences retained; paired-sequence summaries and interactions only after completion.

Each adapter state runs the unchanged synthesis path once. The pre-repair canvas is captured, exact repair/head replay is checked, and the original head is applied to the unrepaired canvas. The trained baseline must reproduce the completed replay within 1e-12 MSE. A deepest-only map must be unchanged by adapter removal. CUDA stays disabled; two CPU threads, nice10. This is a frozen-weight sensitivity analysis, not a retrained architecture ablation, runtime test, or proof that a component is necessary after optimization.
