# A stage-synchronous context rule for shared early exits

The current six-exit decoder executes a four-block full-frame stem, then sends each 256×256 output tile through as many two-block suffix groups as its frozen decoder-side router selects. The pointwise layers in a `DepthConvBlock` need no neighbouring tile. Only the 3×3 depthwise layer does. This makes a one-feature-cell ring the smallest context exchange that can repair the tiling boundary without paying a full-block halo.

Let $A_g=\{t:k_t\ge g\}$ be the tiles still active at suffix group $g$. Immediately before each depthwise convolution, update a shared canvas with the current pre-depthwise activations of **all tiles in $A_g$**. An active tile reads a neighbouring feature only when that neighbour also belongs to $A_g$; otherwise it uses the declared zero or replicate fallback. For a tile at the outside of the image the original full-frame zero boundary remains. An exited tile never provides a stale feature to a deeper stage.

This rule has three useful invariants. When all tiles are active, the depthwise result equals the full-frame convolution, including internal tile corners. When only one interior tile is active, the output equals the ordinary per-tile convolution with the selected fallback. The rule uses the existing route and the same decoded latent, so it adds no route bits. Synthetic all-active, isolated, and partial-active multi-image controls are in [`test_active_canvas_coupling.py`](../../../proof/cpu_early_exit/test_active_canvas_coupling.py). The Kodak replay additionally checks all-deep/no-repair output against full-frame e15.

For the frozen Kodak routes, the extra padded depthwise arithmetic is **0.01087 percentage points** of full synthesis conv-MAC on average. Keeping grid repair changes the deployed mean saving from 25.88374% to an analytical 25.87287%; removing it changes the saving to 26.82359%, because the old repair itself costs 0.95072 percentage points. These figures count convolution multiplications only. The current PyTorch implementation constructs a halo tensor at every depthwise layer, so no wall-clock improvement follows from this arithmetic without a fused kernel and matched end-to-end timing.

The stale-canvas control is an important negative comparator: it keeps an exited tile's last activation available at later groups, where it is no longer stage-aligned with its active neighbour. The first frozen Kodak pilot had a catastrophic mixed-depth case, motivating the active-only rule. The full-cohort comparison is required before claiming that the rule improves quality. Compared with the local Mosaic project's continuously updated cheap path, this is a stricter early-exit rule: tiles cannot re-enter, and inactive tiles do no later computation. It tests how much context can be recovered while preserving that early-exit contract.
